# FollowTask Cyberpunk Professional

## Versi 1.0

### 1. Informasi Aplikasi
- Nama: FollowTask
- Platform: Android
- Bahasa: Kotlin
- Framework: Jetpack Compose
- Desain: Cyberpunk Professional
- Package: id.ruangnalar.followtask
- Minimum Android: 6.0
- Target SDK: 35

### 2. Fitur Utama

#### Dashboard
- Ringkasan aktivitas.
- Statistik tugas.
- Status tugas.

#### Instagram
- Membuka profil Instagram.
- Follow dilakukan secara manual.
- Tombol konfirmasi tugas.
- Jeda konfirmasi 5 detik.

#### Telegram
- Membuka layanan resmi PR.social.
- Mendukung alur Telegram Worker resmi.
- Tidak menjalankan bot otomatis.

### 3. Keamanan
- Tidak menyimpan password.
- Tidak menyimpan token rahasia.
- Tidak menggunakan auto-follow.
- Tidak memalsukan konfirmasi tugas.
- Komisi hanya ditampilkan jika terverifikasi melalui integrasi resmi.
